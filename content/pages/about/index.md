## 자기소개
> 키워드 : 책임, 끈기, 소통

안녕하십니까. 3년 경력의 Python 기반 백엔드 개발자 정희진입니다.<br>
저는 크게 두 가지 강점을 말씀드리고 싶습니다.<br>

첫 번째 강점은 안정적인 실서비스 API 설계와 효율적인 DB 운용 역량입니다.<br>
저는 주로 Python 환경에서 백오피스 및 사용자향 앱 서비스를 위한 RESTful API를 설계하고 구현해 왔습니다. <br>
이 과정에서 API 명세 작성부터 버전 관리 및 인증/인가 로직 구축까지 서비스의 확장성을 고려하며 작업했는데요 <br>
이러한 노력은 개발 효율성 증대와 사용자 경험 향상으로 이어졌습니다.<br>

두 번째는 끈기 있는 문제 해결 능력과 성장에 대한 꾸준한 노력입니다.<br>
저는 매 순간 **책임감**을 가장 중요한 가치로 여기며, 맡은 과제를 회피하지 않고 **끈기** 있게 해결하는 개발자입니다.<br>
특히 계획적인 메모 습관을 통해 복잡한 업무와 예상치 못한 이슈를 마감 기한 내에 체계적으로 해결해 왔으며, <br>
이러한 체계적인 **소통**과 협업 역량은 다양한 팀원들과의 프로젝트를 성공적으로 이끄는 데 큰 도움이 되었습니다.<br>
또한, 기존 백엔드 업무를 넘어 최근에는 플러터를 학습하며 프론트엔드 영역까지 시야를 넓히고 있습니다. <br>
이는 서비스 전체 구조를 이해하고 개발 효율을 높이기 위한 저의 지속적인 노력입니다.<br>

제가 가진 파이썬 기반의 탄탄한 서버 개발 경험과<br>
빠르게 학습하고 적용하는 끈기를 바탕으로 서비스 혁신에 반드시 기여하고 싶습니다.
